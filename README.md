# KillMyParents
Easily remove Xbox 360 Parental/Content Controls, even without knowing the password. KillMyParents is a compilation of Xbox 360 homebrew software set up to make the process as easy as putting the files on a USB drive, plugging it into the Xbox 360, and clicking a few buttons. That's it!

## KillMyParents is a Compilation of Software
All I really did was bundle the software together and set Parental Control Remover by Derf to autorun. KillMyParents is made possible by the following software:
- Parental Control Remover by Derf (source: https://github.com/DerfJagged/ParentalControlRemover/)
- BadUpdate by Grimdoomer (source: https://github.com/grimdoomer/Xbox360BadUpdate/)
- ABadAvatar by bibarub (source: https://github.com/bibarub/XBox360BadUpdate/releases/)
- XeUnshackle by Byrom90 (source: https://github.com/Byrom90/XeUnshackle)
- Xbox 360 Dashboard 17559

The USB Root was set up by using the ConsoleMods.org wiki (https://consolemods.org/wiki/Xbox_360:Bad_Update) as a reference, with several steps omitted for cleanliness, as KillMyParents does not require Aurora, DashLaunch, or XeXMenu for its purposes.
